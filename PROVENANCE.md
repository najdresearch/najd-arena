# Provenance

Najd Arena v0.1 extracts the reusable design and behavior proven in the private `humain-m3` research repository. It starts with a clean Git history so historical run data, restricted datasets, provider configuration, and experiment-specific scripts do not enter the open-source project.

The acceptance corpus is newly authored for this repository and released under CC0-1.0. The software is licensed under Apache-2.0.
