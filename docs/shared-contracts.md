# Shared contracts and private preview

Arena consumes the schemas owned by benchmark. `contracts.lock.json` pins the exact
upstream Git commit and SHA-256 of each schema under `web/lib/contracts`.
CI verifies both local bytes and immutable upstream bytes.

A Najd admin can open `/admin/contract-preview` from the admin page, choose a result
bundle generated by `najd-contract`, and inspect scores, per-label breakdowns, failures,
case outputs and hashes. The route validates schema, digests, labels and case accounting.
It does not independently recompute Python metrics or certify the caller's origin.

| Boundary | Behavior |
|---|---|
| Access | Existing Najd admin authentication required on both page and API |
| Payload | JSON only, maximum 2 MB; unknown versions and additional fields rejected |
| Storage | No database, object-store or queue write; browser/session preview only |
| Privacy | No-store response; no public navigation or bundle logging |
| Publication | Always ineligible; even `arena_managed` in the uploaded JSON is untrusted |
| Scoring | Benchmark owns metric definitions and recomputation; Arena displays reported values |

The preview is a developer integration tool, not an organization submission path. Local
CLI results cannot be reported on the public Arena leaderboard. Managed ingestion,
private organization reports, immutable approvals and publication remain later milestones.

```sh
python3 scripts/check_contracts.py
pnpm test
pnpm web:lint
pnpm web:build
```

The checked-in `.fixture.json` bundle is produced by a fake endpoint with deliberate
format and timeout failures. It is not a measured model result. Python-to-TypeScript
hash parity, tampering, authentication, payload limits and rendering are covered by tests.
